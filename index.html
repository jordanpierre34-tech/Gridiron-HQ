Data provenance & refresh configuration

NFL: nflverse 2026 play-by-play parquet release, aggregated locally on the server. Offensive EPA/play and success rate are mean EPA and mean success over qualifying offensive scrimmage plays. Defensive values use opponent plays. Yards/play uses rushing + passing yards on qualifying plays. Point differential comes from final scores.

College FBS: CollegeFootballData 2026 FBS team directory, season advanced stats, season team stats, games, and player season stats. Missing values remain blank. FBS membership is loaded dynamically for the selected season.

Refresh: This site calls its own backend /api/data. The server caches provider responses and can refresh them when requested. Set CFBD_API_KEY as a server environment variable. Do not place API keys in frontend JavaScript.

Metric caveat: CFBD's advanced success-rate methodology and nflverse's play-level success variable may differ. Compare teams within the same league, not directly across leagues.

Links: CFBD API · CFBD access tiers · nflverse releases.
